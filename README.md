# Sen uchun ❤️ - 3D Particles Experience

Three.js va Tween.js yordamida yaratilgan interaktiv 3D zarrachalar (Particle System) sahifasi.

## ✨ Xususiyatlari
1. **1-bosqich (Sehrli Konvert):** Zarrachalardan shakllangan "Sen uchun" yozuvi, nozik konvert konturi va qizil yurakcha ikonkasi (❤️).
2. **2-bosqich (Kosmik Vorteks):** "Kashf qilish" tugmasi bosilganda zarrachalarning kuchli portlab, aylanuvchi pushti-neon galaktika spiraliga aylanishi.
3. **3-bosqich (Neon Ism):** Vorteks markazidan silliq yig'ilib paydo bo'luvchi yorqin "Josiya" ismi.
4. **4-bosqich (Haqiqiy 3D Atirgul):** Ism ustida qatlam-qatlam ochiluvchi, alohida yorqin konturli barglarga ega, nafas olib tebranuvchi mukammal 3D Atirgul (Rose) modeli.
5. **Qo'shimcha imkoniyatlar:**
   - O'rnatilgan Web Audio API romantik ambient arpejio ohangi (har qanday brauzerda tashqi fayllarsiz ishlaydi).
   - 3D sichqoncha va sensorli ekran parallaks harakati.
   - 30,000 ta porloq neon zarrachalar va yulduzlar foni.

## 🚀 Ishga tushirish
Hech qanday o'rnatishlar talab qilinmaydi. `index.html` faylini istalgan brauzerda ochish kifoya.
